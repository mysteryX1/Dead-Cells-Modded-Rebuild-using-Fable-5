# 死亡细胞网页版 —— 最小可玩版本设计文档

日期：2026-06-11
状态：已与用户确认

## 1. 项目目标

做一个《死亡细胞》风格的网页平台动作游戏，键盘控制，**个人学习/自玩用途，不公开发布**。第一版只做一个手摆小关卡，目标是"可以正常运行、手感跟手"的最小可玩版本。

角色与敌人贴图优先使用从 The Spriters Resource 下载的《死亡细胞》原版提取精灵图（个人用途）；场景允许简化；任何素材获取失败时自动退回代码生成的占位图形，保证游戏始终可运行（素材方案 B + 兜底 C）。

## 2. 技术栈与运行方式

- **Phaser 3**（下载到本地 `lib/phaser.min.js`，不依赖 CDN）
- 原生 ES Module JavaScript，无构建工具
- 物理：Phaser Arcade Physics（AABB）
- 运行：本地静态服务器（如 `python -m http.server`）打开 `index.html`。直接双击 html 会因浏览器安全限制无法加载贴图，README 中说明。

核心设计点：

- 玩家与敌人均使用**状态机**管理动作（待机/跑/跳/下落/翻滚/攻击/受伤/死亡），避免动画与逻辑互相打断
- 所有手感数值（速度、跳跃力、翻滚距离、攻击前后摇、伤害、血量）集中在 `config.js`

## 4. 操作与键位（WASD + JKL）

| 按键 | 动作 |
|---|---|
| A / D | 左右移动 |
| S | 在单向平台上按下 = 下落穿过 |
| K | 跳跃；空中再按一次 = 二段跳 |
| J | 近战攻击，连按出 2 段连击 |
| L | 翻滚（无敌帧） |
| W | 在出口门前进入（需清空敌人） |
| R | 死亡/通关后重开 |

## 5. 移动手感

- 即时加速/即时停止，无惯性滑步，转身瞬间完成
- 短按小跳/长按大跳：松开 K 时若仍在上升则削减上升速度
- 土狼时间：离开平台边缘约 80ms 内仍可起跳
- 二段跳：空中一次额外跳跃，落地重置
- 翻滚：固定距离快速位移，期间无敌、不可转向，结束后约 150ms 冷却

## 6. 战斗

**玩家**：100 HP。

- 攻击：J 在面朝方向生成矩形攻击判定框；命中造成伤害 + 短硬直 + 击退；第二段连击伤害略高
- 受击：扣血 + 击退 + 1 秒受伤无敌（角色闪烁）
- 死亡：显示"YOU DIED"式提示，按 R 重开关卡

**敌人（僵尸 ×1 种，关卡内 4~6 只）**：50 HP，普攻 2~3 刀击杀。

- AI：平台巡逻 → 玩家进入索敌范围（水平约 250px、同层）则追击 → 近身后起手攻击（约 400ms 前摇，给翻滚窗口）
- 死亡播放消失效果

## 7. 关卡、镜头与 UI

- 一张手摆横版地图，约 3~4 屏宽、2 屏高，监狱风格暗色调
- 地图为代码内二维数组：0=空、1=实心砖、2=单向平台（可跳上、可按 S 穿下）；不引入 Tiled
- 内容：地面、悬空单向平台、需二段跳的高台、4~6 只僵尸、终点门
- 胜利条件：清空全部敌人后在门前按 W → "通关！"画面 → R 重玩
- 镜头：平滑跟随玩家（lerp），限制在地图边界内
- UI：左上角红色血条 + 剩余敌人数；底部按键提示

## 8. 素材管线

1. 从 The Spriters Resource 的 Dead Cells 页面下载：玩家（The Beheaded）精灵图、僵尸精灵图、监狱 tileset
2. 处理成规则网格帧，动画只取：待机、跑、跳、下落、翻滚、攻击×2、受伤、死亡
3. 下载 Phaser 3 至 `lib/`
4. **兜底**：任何贴图下载或解析失败 → 自动使用代码生成的占位像素图（玩家=蓝色剪影、僵尸=绿色剪影、砖=深灰描边方块），游戏逻辑不受影响

## 9. 错误处理

- BootScene 监听 Phaser `loaderror` 事件，失败贴图以占位纹理替换
- 无存档、无网络功能，无其他外部失败点
