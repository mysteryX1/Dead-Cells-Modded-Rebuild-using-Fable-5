# 死亡细胞网页版 二期 —— Boss、武器、成长与血条 设计文档

日期：2026-06-12
状态：已与用户确认
前置：一期 MVP 已交付（见 `2026-06-11-dead-cells-web-design.md`），本文档只描述增量。

## 1. 范围

1. 怪物血条（小怪头顶血条 + Boss 屏顶大血条）
2. 接入用户提供的三张单帧立绘（囚徒=玩家、石雕守卫=精英怪、时光守护者=Boss）
3. 精英怪（石雕守卫）
4. Boss 战（独立 Boss 房 + 三套招式 + 二阶段）
5. 武器系统（旧剑/速剑/重剑，W 拾取替换）
6. Run 内成长（红/绿卷轴 + 细胞计数）

**不做（YAGNI）**：随机关卡、多关卡、远程武器、商店、存档、音效、武器随机词缀。

## 2. 素材（单帧立绘模式）

源图在 `assets/` 下（用户手工下载，文件名含"爱给网"）。用 `tools/prepare_singles.py`（Pillow）处理：裁掉透明边、按高度缩放（NEAREST 保持像素风）、输出：

| 输出 | 源图 | 目标高度 | 用途 |
|---|---|---|---|
| `assets/player.png` | 囚徒持金剑立绘 | 48px | 玩家贴图 |
| `assets/elite.png` | 石雕守卫 | 56px | 精英怪贴图 |
| `assets/boss.png` | 时光守护者 | 80px | Boss 贴图 |

- 三张均为**单帧**：无逐帧动画，动作反馈沿用现有闪烁/变色机制
- `src/anims.js` 的 SHEETS 条目增加 `type: 'image' | 'spritesheet'`：player/elite/boss 为 image；zombie 保留 spritesheet 条目（仍 404 → 占位，日后放帧表即可激活）
- **兜底不变**：任何图加载失败（loaderror 或纹理缺失）退回占位矩形——player 蓝 24×40、elite 橙 32×52、boss 紫 40×64、zombie 绿 26×40
- 立绘默认朝右；朝左由 setFlipX 镜像。物理碰撞体尺寸与一期一致（视觉大于碰撞体，底对齐）

## 3. 怪物血条

- 小怪/精英：头顶上方 6px 处宽 24×4px（精英 32×5px）血条，深色底 + 红色填充，跟随移动
- **首次受击后才显示**，死亡随尸体消失；场景重开自动清理（随实体销毁）
- Boss：屏幕顶部居中 400×16px 常驻大血条，下方标注"时光守护者"，setScrollFactor(0)
- 实现：每个实体自带 `scene.add.graphics()`，在自身 update 中重画；die() 时销毁

## 4. 精英怪（石雕守卫）

复用 Zombie 的 FSM 与 AI（巡逻/追击/前摇攻击/硬直/死亡），仅数值与外观不同（`config.js` 新增 ELITE）：

| 项 | 值 |
|---|---|
| HP | 150 |
| 伤害 | 25 |
| 巡逻/追击速度 | 40 / 80 |
| 索敌范围 | 水平 280 / 垂直 60 |
| 攻击范围 / 前摇 | 50px / 600ms |
| 碰撞体 | 30×50 |
| 细胞掉落 | 5 |

- 实现为 `src/entities/Elite.js`，继承 Zombie，构造时注入 ELITE 数值与 'elite' 贴图
- 地图标记 `E`，现有地图中部放 1 只；计入"清空敌人"计数

## 5. Boss 战（时光守护者）

### 流程
- 清空小怪+精英 → 门前按 W → `scene.start('Boss', playerState)` 进入 Boss 房
- 携带状态 `playerState = { hp, maxHp, weaponKey, atkMult, flatBonus, cells }`
- 击败 Boss → "通关！"横幅；玩家死亡 → "YOU DIED"。两种结局按 R 都回到第一关**重开整局**（roguelite）

### Boss 房（BossScene + BOSS_LEVEL 地图）
- 一屏大小（30 列 × 17 行）封闭竞技场：四周实心墙、平坦地面、左右各一块单向跳台
- 玩家从左侧进场，Boss 立于右侧

### Boss 数值与招式（config.js 新增 BOSS）
- HP 400，碰撞体 36×64，移动速度 90（追向玩家保持中距离）
- 招式按"距离 + 全局冷却 1200ms"选择：

| 招式 | 触发距离 | 前摇 | 效果 |
|---|---|---|---|
| 横扫 | < 90px | 500ms（变红） | 面前 70×50 判定框，伤害 22 |
| 冲刺 | 90~300px | 600ms（闪红光） | 以 500 速度横穿场地至撞墙，接触伤害 18，可跳/翻滚躲 |
| 光刃弹幕 | > 300px 或随机 | 400ms | 朝玩家发 3 发橙色光弹（速度 180、伤害 12、碰墙消失） |

- **二阶段**：HP < 50% 时全局冷却降至 700ms，光弹增至 4 发
- 受玩家攻击：扣血 + 白闪，**无硬直无击退**（防无限连）
- 光弹为简单橙色圆形（code 生成纹理），物理 overlap 判定，翻滚无敌可穿过

## 6. 武器系统

`config.js` 新增 WEAPONS（伤害为两段连击 [一段, 二段]）：

| key | 名称 | 伤害 | 出招 | 范围 X |
|---|---|---|---|---|
| old | 旧剑 | [20, 28] | 250ms | 40 |
| fast | 速剑 | [14, 18] | 170ms | 36 |
| heavy | 重剑 | [34, 46] | 380ms | 56 |

- 玩家初始持旧剑（即一期手感不变）；攻击节奏、判定框宽度、伤害全部读当前武器
- 速剑/重剑作为拾取物放在地图两处（标记 `f`/`h`），走近 40px 内按 W 替换；**被换下的武器掉在原地**，可再换回
- 武器拾取判定优先于门（门本就要求清空敌人才生效，位置也不重叠）
- 拾取物外观：小色块+武器名文字（速剑青色、重剑橙色）
- UI：左上角血条下方显示"武器：旧剑"

## 7. Run 内成长

### 卷轴（地图标记 `r` 红 / `g` 绿，共 3 个，其中 1 个放二段跳高台）
- 红卷轴：攻击倍率 +0.15（atkMult 初始 1.0，可叠加）
- 绿卷轴：maxHp +25 并回满血
- 碰到自动拾取，显示一行飘字提示（如"攻击 +15%"，800ms 后消失）

### 细胞
- 小怪死亡掉 1 个、精英掉 5 个；细胞为小蓝紫色圆点，生成后 tween 飞向玩家自动收集
- UI 计数"细胞 N"；**每攒满 10 个 flatBonus +5**（攻击力平添，立即生效，无上限）

### 伤害公式
`实际伤害 = floor((武器伤害[段] + flatBonus) × atkMult)`

成长状态存在 Player 上，随 playerState 带入 Boss 房；R 重开后归零。

- 左上：血条（现有）→ 武器名 → 细胞计数；GameScene 另有"敌人 N"
- BossScene：屏顶 Boss 血条
- 底部按键提示增加"W 拾取武器"

## 9. 文件结构

```
新增：
  src/entities/Elite.js      # 精英怪（继承 Zombie，注入 ELITE 数值）
  src/entities/Boss.js       # Boss FSM（追击/横扫/冲刺/弹幕/死亡）
  src/entities/Pickup.js     # 武器与卷轴拾取物（含飘字）
  src/scenes/BossScene.js    # Boss 房（复用关卡构建逻辑）
  tools/prepare_singles.py   # 三张立绘裁边缩放
修改：
  src/config.js              # WEAPONS / ELITE / BOSS / SCROLL / CELL
  src/level.js               # 主图加 E/f/h/r/g 标记；新增 BOSS_LEVEL
  src/anims.js               # SHEETS 加 type 字段与三张单帧图条目
  src/scenes/BootScene.js    # image 类型加载 + 新占位兜底（elite 橙 / boss 紫）
  src/scenes/GameScene.js    # 血条、细胞、拾取、进 Boss 房；关卡构建逻辑抽出复用
  src/entities/Player.js     # 武器引用、成长属性、伤害计算
  src/entities/Zombie.js     # 头顶血条、细胞掉落、数值改为构造注入（供 Elite 复用）
```

- GameScene 的关卡构建（字符地图→物理组）抽成可复用模块（如 `src/levelBuilder.js` 或基类场景），避免 BossScene 复制粘贴

## 10. 错误处理

- 三张新图沿用 loaderror + 纹理缺失双重兜底，占位色块可完整游玩
- BossScene 进场依赖 playerState：缺省时（直接调试进入）用初始值兜底
