# 死亡细胞 · 网页版（个人学习项目）

## 运行方式

必须通过本地 HTTP 服务运行（直接双击 index.html 会因浏览器安全限制无法加载资源）：

    python -m http.server 8000

然后浏览器打开 http://localhost:8000

## 操作

| 按键 | 动作 |
|---|---|
| A / D | 左右移动 |
| S + K | 站在单向平台上 = 下穿（实心地面上为普通跳跃） |
| K | 跳跃（空中再按 = 二段跳） |
| J | 近战攻击（连按两段连击） |
| L | 翻滚（无敌帧） |
| W | 拾取武器 / 清空敌人后在门前进入 Boss 房 |
| R | 死亡/通关后重开 |

## 素材说明

角色/敌人贴图来自 The Spriters Resource 的《死亡细胞》玩家提取资源，仅供个人学习使用，请勿传播或商用。贴图缺失时游戏自动使用占位图形，不影响游玩。

## 二期内容

- 怪物头顶血条（受击后显示）、Boss 屏顶大血条
- 精英怪石雕守卫（更肉更疼，掉 5 细胞）
- Boss 战：时光守护者（横扫/冲刺/光刃弹幕，半血进入二阶段）
- 武器：旧剑/速剑/重剑，W 拾取替换，旧武器掉原地可换回
- 成长：红卷轴攻击 +15%、绿卷轴血上限 +25 并回满；细胞每 10 个攻击 +5
- 击败 Boss 通关；死亡或通关后按 R 从第一关重开整局（成长归零）

## 三期内容

- HP 数字：玩家与 Boss 血条上叠加「当前/上限」数字
- 关卡扩充：第一关加大，新增第二关（立体爬高 + 尖刺机关 + 双精英），清场进门接 Boss 房
- 尖刺危险：踩中扣血（复用受击无敌帧，不会每帧连扣）
- 远程怪弓手：圆形索敌，进射程蓄力放箭，太近则后退拉开，走到平台边缘自动停步
- 跳扑突进：僵尸/精英在近战射程外、跳扑射程内蓄力起跳（橙色前摇），空中接触造成伤害
- 精英格挡：正面来袭有概率盾挡，抵消伤害并击退玩家，格挡后自身露破绽
- 成群协同：同一时刻仅一名近战敌人进攻（令牌制），其余在玩家两侧包抄等待
- Boss 招式预警：横扫命中区渐亮、冲刺整条跑道闪烁、弹幕收缩紫环，给出可读的躲避窗口
